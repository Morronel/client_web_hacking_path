Module 09 — Cross-Site Scripting (XSS)

Master XSS attack vectors across different injection contexts and learn how browsers parse and execute injected code.

Types of XSS

Reflected XSS

The malicious script comes from the current HTTP request. The server includes unvalidated input directly in the response.

# Server reflects input directly into HTML
@app.route('/search')
def search():
    query = request.args.get('q', '')
    return f"<h1>Results for: {query}</h1>"

Stored XSS

The malicious script is permanently stored on the server (database, comment field, profile). Every user who views the page is affected.

DOM-based XSS

The vulnerability exists in client-side JavaScript that processes data from an untrusted source (like location.hash) and writes it to the DOM unsafely.

// Vulnerable: innerHTML with untrusted data
document.getElementById('output').innerHTML = location.hash.slice(1);

// Safe: textContent escapes HTML
document.getElementById('output').textContent = location.hash.slice(1);

Injection Contexts

The context where your input lands determines which payloads will work:

ContextExampleEscape Strategy
HTML body<p>Hello USER_INPUT</p>Inject <script> or event handlers
HTML attribute<input value="USER_INPUT">Close attribute with ", add event handler
JavaScript stringvar x = 'USER_INPUT';Close string with ', inject code
URL/href<a href="USER_INPUT">Use javascript: protocol

Filter Bypass Techniques

  • Case variation: <ScRiPt> — some filters are case-sensitive
  • Alternative tags: <img>, <svg>, <body>, <details>
  • Event handlers: onerror, onload, onfocus, onmouseover
  • SVG: <svg onload=alert(1)>
  • Encoding: HTML entities, URL encoding, Unicode escapes

Content Security Policy (CSP)

CSP is a browser mechanism that restricts what scripts can execute:

Content-Security-Policy: default-src 'self'; script-src 'self' https://cdn.example.com

Common bypasses: unsafe-inline, unsafe-eval, data: URIs, JSONP endpoints on whitelisted domains.

XSS Impact: Session hijacking (stealing cookies), credential harvesting (fake login forms), CSRF token theft, keylogging, cryptocurrency mining, defacement, and worm propagation.
