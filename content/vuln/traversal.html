Module 16 — Path Traversal

Learn how attackers escape intended directories to read arbitrary files on the server.

What Is Path Traversal?

Path traversal (also called directory traversal) exploits insufficient security validation of user-supplied file paths. By injecting ../ sequences, attackers navigate outside the intended directory to access sensitive files like /etc/passwd, application configs, or source code.

The Core Problem

Vulnerable Code

@app.route('/view')
def view():
    filename = request.args.get('file')
    # DANGEROUS: user controls the entire path
    with open(f'documents/public/{filename}') as f:
        return f.read()

Safe Code

import os

@app.route('/view')
def view():
    filename = request.args.get('file')
    # SAFE: strip path components + validate against whitelist
    safe_name = os.path.basename(filename)
    full_path = os.path.join('documents/public', safe_name)
    real_path = os.path.realpath(full_path)
    if not real_path.startswith(os.path.realpath('documents/public')):
        abort(403)
    with open(real_path) as f:
        return f.read()

Common Traversal Sequences

PayloadPurposeBypasses
../Basic directory upNo filters
....//After single-pass ../ removal → becomes ../Naive replace
%2e%2e%2fURL-encoded ../Pre-decode validation
..%252fDouble URL-encodingSingle decode + check
%00Null byte (legacy)Extension append
..\/Mixed separatorsWindows normalization

High-Value Targets

# Linux targets
/etc/passwd          # User accounts
/etc/shadow          # Password hashes (requires root)
/proc/self/environ   # Environment variables (secrets, API keys)
/app/.env            # Application secrets

# Windows targets
C:\Windows\win.ini
C:\inetpub\wwwroot\web.config
Impact: Path traversal can expose source code, configuration files, credentials, API keys, and in some cases can be chained with file upload or log injection for remote code execution.
