Module 17 — File Upload Vulnerabilities

Understand how insecure file upload handling leads to remote code execution and system compromise.

Why File Uploads Are Dangerous

File upload features allow users to submit arbitrary data to the server. Without proper validation, attackers can upload executable code (webshells, scripts) that the server then runs, granting full control.

Common Validation Techniques & Bypasses

ValidationHow It WorksBypass
Extension blocklistBlocks .php, .py, etc.Use .pHp, .py3, .phtml, double ext .jpg.php
Content-Type checkChecks Content-Type headerClient controls this header — set to image/png

Vulnerable Code

@app.route('/upload', methods=['POST'])
def upload():
    f = request.files['file']
    # DANGEROUS: no validation at all
    f.save(os.path.join('uploads', f.filename))
    return 'Uploaded!'

Safe Code

import uuid, magic

ALLOWED_TYPES = {'image/jpeg', 'image/png', 'image/gif'}

@app.route('/upload', methods=['POST'])
def upload():
    f = request.files['file']
    # Validate MIME type from file content (not header)
    mime = magic.from_buffer(f.read(2048), mime=True)
    f.seek(0)
    if mime not in ALLOWED_TYPES:
        abort(400, 'Invalid file type')
    # Generate safe filename
    ext = {'image/jpeg': '.jpg', 'image/png': '.png', 'image/gif': '.gif'}[mime]
    safe_name = f'{uuid.uuid4()}{ext}'
    f.save(os.path.join('/var/uploads', safe_name))
    return 'Uploaded!'

Common Magic Bytes

PNG:  \x89\x50\x4E\x47\x0D\x0A\x1A\x0A
JPEG: \xFF\xD8\xFF\xE0
GIF:  GIF87a or GIF89a
PDF:  %PDF-
Impact: Unrestricted file upload can lead to remote code execution (RCE), webshell deployment, server takeover, defacement, and data exfiltration. It's consistently ranked in the OWASP Top 10.
