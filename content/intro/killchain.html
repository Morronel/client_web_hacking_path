Cyber Kill Chain & ATT&CK

The Lockheed Martin Cyber Kill Chain

Developed by Lockheed Martin in 2011, the Cyber Kill Chain is a framework that describes the stages of a cyberattack from initial reconnaissance to achieving the attacker's objective. Understanding these phases helps defenders identify and disrupt attacks at each stage — the earlier the disruption, the lower the impact.

The 7 Phases

# Phase Description Web Attack Example
1 Reconnaissance Researching the target — gathering information about systems, people, and infrastructure Subdomain enumeration, directory brute-forcing, Shodan scans, OSINT on employees
2 Weaponization Creating a deliverable payload — combining an exploit with a backdoor Crafting a malicious SQL injection payload, building an XSS payload with cookie stealer
3 Delivery Transmitting the weapon to the target environment Submitting the payload via a web form, sending a phishing email with a malicious link
4 Exploitation Triggering the payload to exploit a vulnerability SQL injection executes on the database, XSS fires in victim's browser, SSTI renders server-side
5 Installation Installing persistent access (backdoor, web shell, malware) Uploading a web shell via file upload vulnerability, creating a rogue admin account
6 Command & Control (C2) Establishing a communication channel for remote control Web shell provides interactive access, reverse shell phones home, DNS tunneling for covert C2
7 Actions on Objectives Achieving the goal — data exfiltration, destruction, or lateral movement Dumping the database, defacing the website, pivoting to internal systems
Defender's advantage: An attacker must succeed at every phase. A defender only needs to break the chain at one point. This is why defense-in-depth — multiple layers of security — is so effective.

MITRE ATT&CK Framework

While the Kill Chain provides a high-level view, the MITRE ATT&CK (Adversarial Tactics, Techniques, and Common Knowledge) framework provides granular detail. It catalogs real-world adversary behaviors into a matrix of tactics (the "why") and techniques (the "how").

Key ATT&CK Tactics

  • Initial Access — how attackers get in (phishing, exploiting public-facing apps)
  • Execution — running malicious code (command injection, scripting)
  • Persistence — maintaining access (web shells, account creation)
  • Privilege Escalation — gaining higher permissions (IDOR to admin, JWT manipulation)
  • Defense Evasion — avoiding detection (obfuscation, encoding payloads)
  • Credential Access — stealing credentials (SQL injection to dump hashes, session hijacking)
  • Collection — gathering target data
  • Exfiltration — stealing data out of the environment
Kill Chain vs ATT&CK: The Kill Chain is linear — it assumes attacks progress through stages in order. ATT&CK is more flexible, recognizing that attackers may skip phases, repeat them, or operate in multiple phases simultaneously. Both frameworks are valuable; use the Kill Chain for high-level understanding and ATT&CK for detailed threat modeling.

Mapping Web Attacks to the Kill Chain

Every web vulnerability you learn in this course maps to one or more Kill Chain phases. Here are some examples:

Web Attack Primary Phase Explanation
Directory brute-forcing Reconnaissance Discovering hidden endpoints and admin panels

Web Shell Upload Installation Establishing persistent remote access to the server
