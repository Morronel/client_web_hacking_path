API Documentation

GET /api/posts

Returns all blog posts in JSON format.

Parameters

NameTypeDescription
category string (optional) Filter posts by category. Available categories: cyberware, hacking, culture, news, hardware

Example Request

GET /api/posts?category=hacking

Example Response

{ "status": "success", "count": 1, "posts": [ { "id": 2, "title": "Decking 101: How to Breach ICE Without Dying", "content": "Every wannabe netrunner thinks...", "author": "gh0stwr1t3r", "category": "hacking", "created_at": "2087-01-01 00:00:00" } ] }

Error Response

{ "status": "error", "message": "SQL error details...", "query": "SELECT * FROM posts WHERE category = '...'" }
