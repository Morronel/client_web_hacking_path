NeonGraph - Social Network GraphQL API

A cyberpunk social network with a GraphQL API. Probe the schema, exploit the resolvers, own the grid.

Challenges

1 Introspection Recon

The GraphQL API has introspection enabled. Use it to discover hidden types and fields that expose sensitive data.

2 Depth Attack

GraphQL queries can be nested deeply through relational fields. There is no depth limit on this API. Overload the server with a deeply nested query (depth > 10).

3 Authorization Bypass

The posts query is supposed to filter out private posts. Does it?

4 GraphQL Injection

The searchUsers query takes a name parameter. The resolver might not sanitize input properly before building its database query.

5 Batch Attack

The API accepts batched queries (JSON array of queries in a single request). There is no rate limiting. Send a batch of more than 5 queries.

6 Field Suggestion Leak

GraphQL error messages are verbose. Misspelling a field name may reveal hidden fields you shouldn't know about.
