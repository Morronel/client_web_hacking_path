NeonPing Network Diagnostics

Welcome to NeonPing, a network diagnostic suite. Each tool below has a command injection vulnerability for you to discover and exploit.

Challenge 1 — Basic Injection

Ping

Run a basic ping against any host. The input is passed directly to os.popen() with no sanitization.

Difficulty: Easy • Hint: Try appending a second command with ; or |
Note: This challenge teaches basic command separator injection. The goal is to read /app/flag.txt.
Launch Ping
Challenge 2 — Blind Injection

DNS Check

Checks whether a domain resolves, but only returns "success" or "failed" — no command output is shown. You must exfiltrate data out-of-band.

Difficulty: Medium • Hint: Redirect output to a file you can read via the web server
Note: This challenge teaches blind injection and out-of-band exfiltration. While you could use ch1 to read the flag file directly, the goal here is to practice writing output to a web-accessible path.
Launch DNS Check
Challenge 3 — Filter Bypass

Filtered Ping

Like the basic ping, but ;, |, &, and backticks are blocked. Can you find another way to inject?

Difficulty: Medium • Hint: Not all command substitution syntax is blocked
Note: This challenge teaches $() substitution and newline-based bypasses. Practice these techniques rather than using ch1's unfiltered endpoint.
Launch Filtered Ping
Challenge 4 — IFS Bypass

Traceroute

Runs traceroute with subprocess.run(shell=True). Semicolons and pipes are blocked, but there are other ways to chain commands.

Difficulty: Medium • Hint: $IFS can substitute for spaces; newlines can separate commands
Note: This challenge teaches $IFS as a space replacement. Practice the technique here rather than bypassing via a simpler endpoint.
Launch Traceroute
Challenge 5 — Space Bypass

Whois

Looks up WHOIS records for a domain. Spaces are strictly blocked by a regex filter. Find a way to run commands without spaces.

Difficulty: Hard • Hint: Brace expansion {cmd,arg} or $IFS can replace spaces
Note: This challenge teaches space-free payloads using input redirection (<) and brace expansion. The goal is to practice these advanced bypass techniques.
Launch Whois
