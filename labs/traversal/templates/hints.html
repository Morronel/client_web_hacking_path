Challenge Hints

Stuck? Each challenge exploits a different weakness in path handling. Read the descriptions carefully and think about how the server processes your input.

Challenge 1 — Basic Traversal

Endpoint: GET /view?file=

How it works: The server reads documents/public/<file> with no sanitization at all. The user-supplied filename is concatenated directly into the path.

Hint: Use ../ sequences to escape the public directory and reach /app/secret/flag.txt.

open(f"documents/public/{file}")

Challenge 2 — Null Byte Bypass

Endpoint: GET /view-safe?file=

How it works: The server appends .txt to the filename, so you can't normally request arbitrary extensions. However, if the server detects a %00 (null byte) in the input, it truncates the string at that point and does not append the extension—simulating the classic null-byte truncation bug found in older languages and frameworks.

Hint: Combine path traversal with %00 to load /app/secret/flag2.txt.

file = file + ".txt" # unless %00 is present

Challenge 3 — Filter Bypass

Endpoint: GET /view-filtered?file=

How it works: The server strips ../ from the input, but only in a single pass. After one round of replacement, the result is used directly.

Hint: Craft a string that, after ../ is removed once, still produces ../. Think: ....//.

sanitized = file.replace("../", "")

Challenge 4 — Encoding Evasion

Endpoint: GET /download?path=

How it works: The server checks the raw query parameter for .. and /etc, then URL-decodes it after the check. If your payload is URL-encoded, it passes the blocklist but decodes into traversal characters.

Hint: URL-encode the dots and slashes: %2e%2e%2f becomes ../ after decoding. Target: /app/secret/flag4.txt.

if ".." in path_param: # checked BEFORE decode block() decoded = urllib.parse.unquote(path_param) # decoded AFTER check

Challenge 5 — Whitelist Bypass

Endpoint: GET /api/doc?name=

How it works: The server checks if the requested name ends with one of the allowed filenames (readme.txt, report.txt, manual.txt). It does not verify that the name contains no directory traversal sequences.

Hint: A name like ../../secret/flag5/readme.txt ends with readme.txt, passing the whitelist, while still traversing to a different directory.

if any(name.endswith(allowed) for allowed in whitelist): allow() # no check for ../ in the name
