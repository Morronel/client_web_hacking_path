Path Traversal Lab

MegaCorp's document viewer has several endpoints for accessing files. Each one has a different "security" mechanism. Your mission: break them all and recover the hidden flags from the restricted sectors.

Note: Each challenge uses a different base directory and targets a different flag file. While cross-reading is technically possible via traversal, the goal is to practice each specific bypass technique against its intended endpoint.

Challenge 1 — Basic Traversal

File Viewer

The /view endpoint reads files from the documents/public/ folder. No filtering is applied to user input.

GET /view?file=readme.txt

Target: /app/secret/flag.txt

Open Viewer

Challenge 2 — Filter Bypass

Filtered Viewer

The /view-filtered endpoint reads from documents/shared/ and strips ../ from the input. But the filter only runs once—can you sneak past it?

GET /view-filtered?file=memo.txt

Target: /app/secret/flag2.txt

Open Filtered Viewer

Challenge 3 — Encoding Evasion

Download Endpoint

The /download endpoint reads from documents/archive/ and blocks .. and /etc in the raw request. But it URL-decodes the path after the security check.

GET /download?path=changelog.txt

Target: /app/secret/flag3.txt
