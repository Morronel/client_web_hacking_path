Path Traversal Lab

MegaCorp's document viewer has several endpoints for accessing files. Each one has a different "security" mechanism. Your mission: break them all and recover the hidden flags from the restricted sectors.

Challenge 1 — Basic Traversal

File Viewer

The /view endpoint reads files from the public documents folder. No filtering is applied to user input.

GET /view?file=readme.txt

Target: /app/secret/flag.txt

Open Viewer

Challenge 2 — Null Byte Bypass

Safe Viewer

The /view-safe endpoint forces a .txt extension on all requests. But legacy null-byte handling might let you truncate the path.

GET /view-safe?file=readme

Target: /app/secret/flag2.txt

Open Safe Viewer

Challenge 3 — Filter Bypass

Filtered Viewer

The /view-filtered endpoint strips ../ from the input. But the filter only runs once—can you sneak past it?

GET /view-filtered?file=readme.txt

Target: /app/secret/flag3.txt

Open Filtered Viewer

Challenge 4 — Encoding Evasion

Download Endpoint

The /download endpoint blocks .. and /etc in the raw request. But it URL-decodes the path after the security check.

GET /download?path=readme.txt

Target: /app/secret/flag4.txt

Open Download

Challenge 5 — Whitelist Bypass

Document API

The /api/doc endpoint uses a whitelist: only readme.txt, report.txt, and manual.txt are allowed. But the check only verifies the filename ends with an approved name.

GET /api/doc?name=readme.txt

Target: /app/secret/flag5/readme.txt

Open API
